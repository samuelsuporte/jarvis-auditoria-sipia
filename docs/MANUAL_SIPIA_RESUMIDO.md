# 📘 Resumo Operacional — SIPIA Conselho Tutelar

## 1. O que é o SIPIA?
O Sistema de Informação para Infância e Adolescência (SIPIA) é uma base nacional destinada ao registro e acompanhamento de violações de direitos de crianças e adolescentes, bem como das medidas de proteção aplicadas pelos Conselhos Tutelares[cite: 6, 7].

## 2. Acesso ao Sistema
- **URL Oficial (Produção):** `https://sipiact.mdh.gov.br/`[cite: 23, 25]
- **Autenticação:** O acesso é realizado obrigatoriamente através do login único do **GOV.BR** (requer conta nível Prata ou Ouro)[cite: 10, 14, 25].

## 3. Principais Módulos Operacionais
1. **Cadastros:** Registro de crianças, adolescentes, responsáveis e denúncias[cite: 9, 13, 16, 43, 45].
2. **Medidas de Proteção:** Aplicação e acompanhamento de medidas previstas no Estatuto da Criança e do Adolescente (ECA)[cite: 7, 18, 43, 47, 62].
3. **Relatórios:** Emissão de dados consolidados por unidade para prestação de contas[cite: 8, 19, 110, 112].
